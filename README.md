# Ticari Otomasyon Sistemi

Bu proje, C# (.NET Framework) ve Entity Framework kullanılarak geliştirilmiş bir **Ticari Otomasyon Sistemi**dir. DevExpress UI bileşenleriyle zenginleştirilmiş kullanıcı arayüzüne sahiptir. Amaç; firmalar, müşteriler, ürünler ve faturalandırma gibi temel ticari işlemleri yönetebilecek bir masaüstü uygulaması oluşturmaktır.

---

## 🔧 Kullanılan Teknolojiler

- **Dil**: C# (.NET 9)
- **ORM**: Entity Framework Core
- **UI**: DevExpress WinForms
- **Veritabanı**: MS SQL Server
- **Mimari**: Katmanlı Mimari

---

## 🧪 Başlatmak İçin

1. Projeyi Visual Studio ile açın.
2. Gerekirse NuGet paketlerini geri yükleyin.
3. `DbUrunlerContext` içinde tanımlı olan SQL Server bağlantı cümlesini kendi bilgisayarınıza göre güncelleyin.
4. Giriş formunu veya `FrmMainPage`'i `Startup Form` olarak ayarlayın.
5. Uygulamayı çalıştırın.

---

## 📌 Notlar

- Öğrenmek için geliştirilen bir projedir.
- DevExpress bileşenlerinin düzgün çalışması için lisanslı sürümünüz olmalıdır.
- Proje EF Core ile çalışacak şekilde yeniden yapılandırılmıştır.
